# RAG FINAL Implementation Plan

**Goal:** 在现有 RAG 上加入认证、文档权限和候选阶段隔离，保留检索算法。
**Architecture:** SQLite 为身份、会话和权限唯一依据；Argon2id + HS256 JWT + SQLite 会话撤销；所有 API 强制认证；授权 document_id 同时传入 Vector/BM25/别名/扩展。None 表示内部调用不限定，[] 必须返回空。单 API worker。
**Spec:** 用户附件《RAG FINAL》完整任务；本计划按用户已授权的连续执行方式实施。
